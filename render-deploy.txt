  ---
  Render Deployment Guide

  Stack: FastAPI backend + Vite/React frontend + PostgreSQL

  3 Services to Create on Render

  1. PostgreSQL (free, expires 90 days)
  2. Backend — Web Service (Docker)
  3. Frontend — Static Site (not Docker, build only)

  ---
  Step 1 — PostgreSQL

  1. Render dashboard → New → PostgreSQL
  2. Name it notpad-db, region closest to you, plan Free
  3. Create → copy the Internal Database URL (use this for backend)

  ---
  Step 2 — Backend Web Service

  1. New → Web Service → connect your GitHub repo
  2. Settings:
    - Root Directory: backend
    - Runtime: Docker
    - Dockerfile Path: ./Dockerfile
    - Plan: Free
  3. Environment Variables (add all):

  ┌────────────────┬────────────────────────────────────────┐
  │      Key       │                 Value                  │
  ├────────────────┼────────────────────────────────────────┤
  │ DATABASE_URL   │ Internal DB URL from Step 1            │
  ├────────────────┼────────────────────────────────────────┤
  │ SESSION_SECRET │ random 32+ char string                 │
  ├────────────────┼────────────────────────────────────────┤
  │ CORS_ORIGINS   │ ["https://YOUR-FRONTEND.onrender.com"] │
  ├────────────────┼────────────────────────────────────────┤
  │ API_BASE_URL   │ https://YOUR-BACKEND.onrender.com      │
  ├────────────────┼────────────────────────────────────────┤
  │ GROQ_API_KEY   │ your Groq key                          │
  ├────────────────┼────────────────────────────────────────┤
  │ DEBUG          │ false                                  │
  └────────────────┴────────────────────────────────────────┘

  4. Create service → note the backend URL

  ---
  Step 3 — Fix Frontend for Production

  Frontend Dockerfile runs npm run dev — won't work as static site. Need to
  update it.

  Option A (recommended): Deploy as Static Site — no Docker needed.

  On Render:
  1. New → Static Site → connect same repo
  2. Settings:
    - Root Directory: frontend
    - Build Command: npm install && npm run build
    - Publish Directory: dist
  3. Environment Variable:

  ┌──────────────────┬───────────────────────────────────┐
  │       Key        │               Value               │
  ├──────────────────┼───────────────────────────────────┤
  │ VITE_BACKEND_URL │ https://YOUR-BACKEND.onrender.com │
  └──────────────────┴───────────────────────────────────┘

  ---
  Step 4 — Update Backend CORS

  Once frontend URL is known, go back to backend service → update CORS_ORIGINS
  to include the actual frontend URL.

  ---
  Caveats (Free Tier)

  - Backend sleeps after 15 min inactivity — first request takes ~30s cold start
  - DB expires in 90 days — need to recreate or upgrade
  - Uploads volume won't persist on free tier (ephemeral disk) — files lost on
  redeploy. If uploads matter, use Cloudinary or S3

  ---
  Start with Step 1 — need the DB URL before backend can be configured. Want me
  to help fix any specific part?
